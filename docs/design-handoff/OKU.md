# Tasarım teslim paketi (v2.0.0)

Bu klasör, v2.0.0 arayüz yenilemesinin teslim paketidir. Dosyalar **üretim kodu
değildir** — `.dc.html` dosyaları görünümü ve davranışı gösteren tasarım
prototipleridir; `support.js` yalnız prototipi tarayıcıda çalıştırır.

Okuma sırası:

1. `BASLA.md`
2. `ARAYUZ-YENILEME-PROMPT-v2.md` — uygulama talimatı (kurallar, ekran→dosya eşlemesi)
3. `README.md` — design tokens, 18 ekranın tarifi, etkileşimler, state listesi
4. `Yeni Tasarım.dc.html` — birebir uygulanacak tıklanabilir tasarım
5. `i18n-EN.md` — yeni/değişen metinlerin EN karşılıkları
6. `github.md` — ekran → kaynak dosya eşlemesi

Karşılaştırma referansı: `Mevcut Arayüz.dc.html`, `Mevcut Ana Menü.dc.html`.

Paketteki `public/assets/**` dosyaları repodakilerle bayt-bayt aynı olduğu için
kopyalanmadı — görseller `public/assets/` altından kullanılır.
